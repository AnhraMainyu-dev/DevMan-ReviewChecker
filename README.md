# Скрипт для отправки уведомлений проверки уроков Devman

Скрипт предназначен для автоматической проверки наличия ревью уроков на онлайн-курсе для веб-разработчиков [dvmn.org](https://dvmn.org/).

### Как установить

Для отправки уведомлений на Телеграм вам потребуется токен вашего бота в Телеграме, который вы можете получить во время создания бота, а также ваше персональный id.
Они должны быть указаны в файле окружения .env в виде:
```commandline
TG_BOT_TOKEN=
TG_CHANNEL_ID=
```

Python3 должен быть уже установлен. 
Затем используйте `pip` (или `pip3`, если есть конфликт с Python2) для установки зависимостей:
```
pip install -r requirements.txt
```

### Как использовать

Запустите скрипт командой:
```
python auto_check_review.py.py
```
Скрипт будет отправлять вам уведомление как только ревьюер вернёт вам работу, вместе со статусом проверки и ссылкой на урок.
Для возможности отправки личных сообщений вам нужно запустить бота вручную хотя бы один раз.
